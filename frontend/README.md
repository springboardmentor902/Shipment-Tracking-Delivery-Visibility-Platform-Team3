# ShipTrack Pro frontend

A Vite + React + Tailwind frontend for ShipTrack Pro.

## Requirements

- Node.js 18 or newer
- ShipTrack Pro backend running at `http://localhost:8081`

## Run locally

```bash
npm install
npm run dev
```

The app runs on [http://localhost:3000](http://localhost:3000). The API base URL is configured in `.env` as `VITE_API_BASE_URL=http://localhost:8081/api`.

## Production build

```bash
npm run build
npm run preview
```
